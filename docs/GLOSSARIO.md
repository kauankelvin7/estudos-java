# Glossário rápido

| Termo | Significado neste repositório |
|---|---|
| Invariante | Regra que precisa ser verdadeira durante toda a vida de um objeto. |
| DTO | Objeto de transferência usado na interface HTTP para evitar expor a entidade diretamente. |
| ORM | Mapeamento entre objetos e linhas relacionais, usado no Hibernate. |
| JDBC | API Java para executar SQL com conexões e transações explícitas. |
| Stream | Pipeline declarativo de operações em elementos, sem armazenar dados por si só. |
| Lambda | Função anônima usada onde uma interface funcional é esperada. |
| H2 | Banco relacional em memória para exemplos e testes. |
| NoSQL | Família de modelos não relacionais; aqui usamos documentos MongoDB. |
| CI | Processo automatizado de compilação e verificação executado a cada alteração. |
| REST | Estilo de desenho de APIs HTTP orientadas a recursos. |
